A run's life

Provision: plan → approval → apply → verify. Retire: plan(destroy) → approval → unprotect → apply → verify-absent.

stateDiagram-v2
  [*] --> queued
  queued --> running: no earlier unfinished run on this resource
  running --> blocked: credential binding missing or revoked
  blocked --> running: binding fixed
  running --> awaiting_approval: plan needs manual approval
  awaiting_approval --> running: approve (plan sha must match)
  awaiting_approval --> cancelled: reject
  running --> succeeded: all steps succeeded or skipped
  running --> failed: a step failed
  running --> uncertain: mutating attempt lost its lease
  uncertain --> running: late result accepted
  uncertain --> failed: operator closes
  failed --> running: retry-filesystem (grow-root / verify-root only)
  queued --> cancelled: superseded or cancelled
  running --> cancelled: cancel (no active mutating attempt)
  succeeded --> [*]
  failed --> [*]
  cancelled --> [*]

Agent protocol

Results sit in a durable outbox until the server acknowledges them; every reconnect replays what is unacknowledged.

    AG->>GW: Heartbeat(active ids) → lease renewed

Token handling: what the reviews found

The crypto is sound; the trust model is not. The lab repo, and anyone with a web session, decide where secrets go.

IDSevFindingAffects
F1/F17HighRepo-chosen code runs at plan time with the privileged token, before any approval; default approval is automaticProxmox token, backend secrets
F18HighObserve runs (~288/day per installation) send the token to the repo-chosen endpoint with no approvalProxmox token
F2HighAny web session can repoint the repo; the Git credential follows the new URLAll secrets, Git credential
F22MedOne data-dir backup plus the DB decrypts everything: KEK, cookie key ring, CA keyEverything
F3MedToken over http:// or unverified TLS; the CA never reaches OpenTofuProxmox token
F4MedThe planning agent's own change count decides whether approval is neededEverything apply uses
F5/F19/F20MedAny agent, any store key, even a local runtime can receive the tokenProxmox token, future SSH keys
F6/F21MedSessions can't be revoked; a missing CA is silently re-createdSession, agent trust
F7LowAgent outputs unmasked; server masking is memory-only; literal matchingAttempt secrets
F8–F16LowToken in argv, unbounded renewal, env in podman metadata, Git http/accept-new, setup raceVarious
